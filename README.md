# Tic-Tac-Toe — Bright Wooden Edition

This update uses the **exact background image supplied by the client** as the full-page background and keeps the supplied logo unchanged.

## Visual changes
- Exact supplied blue/cream/yellow illustrated background.
- Wooden-look game squares with warm wood gradients, grain-like inset details and raised edges.
- Bright X (pink/red) and O (blue) symbols, with a cheerful matching card design.
- Logo in the header, speaker toggle, and restart control.

## Sound
All sounds are generated by the browser's Web Audio API (no extra sound files):
- X: lower wooden click sound.
- O: brighter high-pitched pop.
- Winning: ascending celebratory notes.
- Draw: gentle descending notes.
- Restart: short reset chime.
- Toggleable light background melody.

Browsers usually require a click/tap before audio can play. Start a game and sound should begin; use the speaker button to mute/unmute.

## Game features retained
- Same-device two-player
- AI (Easy, Medium, Hard)
- Online multiplayer with room codes (Socket.IO)
- Scores, rematch/restart, responsive layout

## Run
1. Install Node.js.
2. Extract this ZIP and open its folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

Online play requires deploying the Node.js server to a host that supports WebSockets/Socket.IO; static hosting alone is not enough.
